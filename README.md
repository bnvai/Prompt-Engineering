# Prompt-Engineering

## AI Prompt Engineering Mastery Tracker

This repository tracks learning progress for the course:
- **Video:** https://www.youtube.com/watch?v=8ib4Qnh2HFE

## Build Guide (What to Do)

Use this workflow each study session:
1. Watch a small section of the video (10–20 minutes).
2. Capture key concepts (frameworks, tactics, failure modes).
3. Create 3–5 prompts to practice the concept.
4. Test prompts on at least 2 model types (reasoning + lightweight).
5. Record outcomes, mistakes, and improved prompt versions.
6. Convert learnings into reusable prompt templates.
